Access control · query performance

When valid incidents disappeared from view

Support users had the right roles, but some expected Incident records were missing from their list views. The investigation traced the behavior to a read ACL condition that was too restrictive.

01 Investigate

Reproduce the gap

  • Impersonated affected users to reproduce the missing records.
  • Used Debug Security Rules to trace ACL evaluations.
  • Found a failing Incident read ACL that depended on a field that was inconsistently populated and not indexed.

02 Collaborate

Use AI as a second set of eyes

  • Used Copilot to summarize the ACL evaluation stack and review the script for logic pitfalls.
  • AI surfaced the non-indexed field as a potential source of inconsistent behavior under load.
  • Manually checked each suggestion against the platform behavior before making changes.

03 Resolve

Make visibility predictable

  • Refactored the ACL to use a reliable, indexed field.
  • Added a safe fallback condition and documented the ACL logic.
  • Validated with impersonation tests across roles; record visibility returned in list and related views, with improved query performance.
